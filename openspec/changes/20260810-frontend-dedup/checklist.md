# Checklist: 前端地图组件去重

## 功能验收

### 空间查询（SpatialQuery）
- [ ] 点选查询：点击地图某点，500m 缓冲区内要素正确显示
- [ ] 矩形框选：拖拽绘制矩形，范围内要素正确显示
- [ ] 圆形框选：两次点击绘制圆形，范围内要素正确显示
- [ ] 结果列表分页正常（>10 条时分页控件出现）
- [ ] 鼠标悬停结果项时地图要素高亮
- [ ] 点击结果项时地图飞行定位
- [ ] 清除结果按钮：所有图层和数据源被正确移除
- [ ] 切换绘制模式时光标样式正确（crosshair）

### 专题检索（FeatureSearch）
- [ ] 输入关键字搜索，结果列表正确显示
- [ ] 点击结果项地图飞行定位
- [ ] 搜索结果在地图上正确标绘（点/线/面不同样式）
- [ ] 鼠标悬停结果项时光标变为 pointer

### 网络分析（NetworkAnalysis）
- [ ] 最短路径：点击 2+ 途经点，执行分析后路径正确渲染
- [ ] 服务区分析：设置中心点和半径，执行后服务区面正确渲染
- [ ] 长春底图正常加载（栅格图 + 矢量路网）
- [ ] 结果摘要文字正确显示
- [ ] 清除全部按钮：路径点、路径线、服务区面被正确移除
- [ ] 组件关闭时恢复京津冀底图

### 空间分析（SpatialAnalysis）
- [ ] 缓冲区分析：绘制图形并设置半径，缓冲区正确渲染
- [ ] 叠置分析：选择数据集后叠置结果正确渲染
- [ ] 清除按钮：绘制图形和分析结果被正确移除

### 地图量算（MapMeasure）
- [ ] 距离量算：点击多个点，总距离正确显示
- [ ] 面积量算：点击多个点闭合，面积正确显示
- [ ] 预览线（虚线）跟随鼠标移动正常
- [ ] 双击或右键完成量算
- [ ] 清除按钮：量算结果和标记被正确移除

### 数据大屏（DataDashboardView）
- [ ] 点击县区后灾情评估面板正常显示
- [ ] 评估灾情后地震图层正确渲染（双缓冲区 + 支援点/物资点/已损毁点）
- [ ] 切换县区时旧地震图层被正确清理
- [ ] 弹窗（缓冲区分析/救援调度）正常打开和关闭

### Agent 聊天（changchunBasemap）
- [ ] Agent 执行最短路径分析时长春底图正常加载
- [ ] Agent 执行服务区分析时长春底图正常加载
- [ ] 长春路网矢量线正确渲染
- [ ] 底图与路网对齐（无偏移）

## 规范检查

- [ ] 所有新增函数有 JSDoc 注释
- [ ] 组件文件行数未因重构而增加
- [ ] 无未使用的 import 残留
- [ ] 无未使用的旧函数定义残留
- [ ] `utils/map.js` 新增函数遵循现有命名风格（camelCase）
- [ ] `composables/useMapLayers.js` 遵循 useShortestPath.js 的模式

- [ ] `removeLayersSafe()` 行为与原各组件 cleanup 函数完全一致
- [ ] `changchunBoundsToWGS84Coords()` 返回值与原内联四角转换完全一致
