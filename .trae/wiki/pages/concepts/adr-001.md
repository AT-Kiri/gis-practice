# 技术选型决策 ADR-001

## 1. 状态

**已接受**（Accepted）

## 2. 背景

项目需要构建一个城市综合防灾应急管理 GIS 系统，要求：
- 地图可视化能力强
- 组件化开发
- 状态管理清晰
- 构建工具高效

## 3. 决策

采用以下技术栈：

| 技术 | 版本 | 选择理由 |
|------|------|---------|
| **Vue 3** | 3.x | Composition API 提供更灵活的代码组织 |
| **Pinia** | 2.x | 官方推荐的状态管理，比 Vuex 更轻量 |
| **MapboxGL** | 2.x | 高性能 WebGL 地图引擎，社区活跃 |
| **Vite** | 4.x | 极快的构建速度和 HMR |
| **Ant Design Vue** | 4.x | 企业级 UI 组件库，设计规范统一 |

## 4. 后果

### 4.1 正面

- Composition API 便于逻辑复用
- Pinia 的 TypeScript 支持更好
- Vite 开发体验极佳
- Ant Design Vue 组件丰富

### 4.2 负面

- MapboxGL 商业使用需授权（教育免费版可用）
- Vite 与传统 CJS 模块兼容性需注意

## 5. 替代方案

| 技术 | 未选理由 |
|------|---------|
| React | Vue 3 学习成本更低，团队更熟悉 |
| Vuex | Pinia 是官方推荐的继任者 |
| OpenLayers | MapboxGL 性能更优，文档更完善 |
| Webpack | Vite 构建速度更快 |
