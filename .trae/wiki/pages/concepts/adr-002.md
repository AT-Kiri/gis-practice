# SuperMap iServer 服务选型决策 ADR-002

## 1. 状态

**已接受**（Accepted）

## 2. 背景

项目需要 GIS 服务平台来发布地图服务、空间数据服务、网络分析服务，要求：
- 支持 RESTful API
- 支持 WMS/WMTS/WFS 标准
- 支持空间查询和网络分析
- 支持自定义数据源接入

## 3. 决策

采用 **SuperMap iServer 11i** 作为 GIS 服务平台。

## 4. 服务配置

| 服务 | URL 前缀 | 用途 |
|------|---------|------|
| 世界底图 | `/iserver/services/map-world` | 全球底图 |
| 京津冀专题图 | `/iserver/services/map-jingjin` | 区域专题图 |
| 长春市区图 | `/iserver/services/map-changchun` | 网络分析底图 |
| 数据服务 | `/iserver/services/data-jingjin` | 空间数据查询 |
| 网络分析 | `/iserver/services/transportationanalyst-sample` | 路径/服务区分析 |

## 5. 前后端通信

```js
// Vite proxy 配置
proxy: {
  '/iserver': {
    target: 'http://localhost:8090',
    changeOrigin: true,
  },
}
```

## 6. 后果

### 6.1 正面

- 完整的 GIS 服务栈
- REST API 设计规范
- 与 SuperMap iDesktopX 数据无缝衔接

### 6.2 负面

- 商业软件，教育版限制
- 部署和调优有一定学习成本

## 7. 替代方案

| 方案 | 未选理由 |
|------|---------|
| GeoServer | Java 生态但文档较少 |
| ArcGIS Server | 商业授权费用高 |
| 自建 GeoJSON 服务 | 缺乏空间分析能力 |
