## 4. 灾情等级划分标准

### 4.1 灾情综合指数 (DDI) 计算公式

```
DDI = Σ (全局权重_i × 标准化指标值_i)
    = 0.2457 × D_norm + 0.1752 × P_norm + 0.1409 × L_norm
    + 0.1352 × M_norm + 0.1057 × H1_norm + 0.0876 × T_norm
    + 0.0744 × I_norm + 0.0352 × H2_norm
```

### 4.2 指标标准化方法（极值标准化）

将原始数据映射到 0~100 区间：

```
norm_value = (raw_value - min_value) / (max_value - min_value) × 100
```

- `min_value` 和 `max_value` 为各指标的历史/区域阈值
- 若 raw_value ≤ min_value，norm_value = 0
- 若 raw_value ≥ max_value，norm_value = 100

### 4.3 灾情等级划分

DDI 阈值（80/60/40）参照 **SL 579-2012《洪涝灾情评估标准》** 表5 年度洪涝灾情评估值等级划分：
- 特别重大：r ≥ 80
- 重大：60 ≤ r < 80
- 较大：5X ≤ r < 60
- 一般：r < 5X（X为参数均值，此处取40）

等级名称与死亡人数标准参照 **《国家地震应急预案》（国办函〔2025〕102号）** §1.4 地震灾害分级。

| 等级 | 名称     | DDI 区间   | 对应《国家地震应急预案》死亡人数标准 |
|------|----------|------------|----------------------------------|
| Ⅰ级  | 特别重大 | DDI ≥ 80   | 200人以上死亡（含失踪）           |
| Ⅱ级  | 重大     | 60 ≤ DDI < 80 | 30人以上、200人以下死亡         |
| Ⅲ级  | 较大     | 40 ≤ DDI < 60 | 10人以上、30人以下死亡           |
| Ⅳ级  | 一般     | DDI < 40   | 10人以下死亡                     |

## 6. 编码实现参考

### 6.1 Python 实现核心逻辑

```python
# 全局权重常量
WEIGHTS = {
    "deaths": 0.2457,          # C11 死亡人口
    "injured": 0.0744,         # C12 受伤人口
    "missing": 0.1352,         # C13 失踪人口
    "affected_pop": 0.1752,    # C21 受灾人口
    "evacuated": 0.0876,       # C22 紧急转移安置人口
    "collapsed_houses": 0.1057, # C31 倒塌房屋
    "damaged_houses": 0.0352,  # C32 严重损坏房屋
    "economic_loss": 0.1409,   # C41 直接经济损失（万元）
}

# 指标阈值（按区域调整）
THRESHOLDS = {
    "deaths":          (0, 300),
    "injured":         (0, 1000),
    "missing":         (0, 100),
    "affected_pop":    (0, 100000),
    "evacuated":       (0, 100000),
    "collapsed_houses":(0, 10000),
    "damaged_houses":  (0, 50000),
    "economic_loss":   (0, 1000000),
}

def normalize(raw: float, min_val: float, max_val: float) -> float:
    """极值标准化到 0~100"""
    if raw <= min_val:
        return 0.0
    if raw >= max_val:
        return 100.0
    return (raw - min_val) / (max_val - min_val) * 100.0

def calculate_ddi(data: dict) -> float:
    """计算灾情综合指数 DDI"""
    ddi = 0.0
    for key, weight in WEIGHTS.items():
        min_val, max_val = THRESHOLDS[key]
        norm = normalize(data.get(key, 0), min_val, max_val)
        ddi += weight * norm
    return round(ddi, 2)

def get_disaster_level(ddi: float) -> dict:
    """获取灾情等级"""
    if ddi >= 80:
        return {"level": 1, "name": "特别重大", "color": "#e53e3e"}
    elif ddi >= 60:
        return {"level": 2, "name": "重大", "color": "#dd6b20"}
    elif ddi >= 40:
        return {"level": 3, "name": "较大", "color": "#d69e2e"}
    else:
        return {"level": 4, "name": "一般", "color": "#38a169"}

# 使用示例
disaster_data = {
    "deaths": 50,
    "injured": 300,
    "missing": 10,
    "affected_pop": 50000,
    "evacuated": 20000,
    "collapsed_houses": 3000,
    "damaged_houses": 10000,
    "economic_loss": 200000,
}
ddi = calculate_ddi(disaster_data)
result = get_disaster_level(ddi)
print(f"DDI = {ddi}, 等级 = {result['level']}（{result['name']}）")
```

## 7. 权重来源与参考文献

1. **SL 579-2012《洪涝灾情评估标准》**（中华人民共和国水利部，2012）
   - 年度洪涝灾情评估公式：C = 0.3D + 0.2P + 0.2A + 0.1L + 0.1F + 0.1H
   - 准则层权重比例由此推导：人员伤亡:受灾范围:房屋损毁:经济损失 ≈ 3:2:1:1

2. **《国家地震应急预案》**
   - 以死亡人数作为首要分级指标，确定 B1 子指标中死亡人口权重最高
   - 灾害等级四级划分标准（特别重大/重大/较大/一般）

3. **Saaty T.L. (1980). The Analytic Hierarchy Process. McGraw-Hill.**
   - AHP 方法论基础：1-9 标度判断矩阵、一致性检验（CR < 0.1）
